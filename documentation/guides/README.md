# Guides

This folder is for practical runbooks: commands, workflows, and execution notes.

- [Command Guide](COMMAND_GUIDE.md): broad command reference for the full BugNIST Diff3F workflow.
- [Point Cloud Diff3F Pipeline](POINTCLOUD_DIFF3F_PIPELINE.md): focused point-cloud pipeline guide.
- [Landmark Benchmarking](LANDMARK_BENCHMARKING.md): manual Blender landmarks and PCK/error evaluation for Diff3F correspondences.
- [Interactive 3-D Correspondences](INTERACTIVE_CORRESPONDENCES.md): inspect two meshes, benchmark lines, landmark metrics, and arbitrary surface points in a standalone browser viewer.
- [Shared-PCA K-Means Clustering](PCA_KMEANS_CLUSTERING.md): discrete k-way cluster maps built on top of the shared-PCA RGB colors.

If you are unsure where to start, open `COMMAND_GUIDE.md`.
