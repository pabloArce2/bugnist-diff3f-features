# Results

Readable summaries of completed BugNIST/Diff3F experiments.

- [Cricket Landmark Benchmark Summary](CRICKET_LANDMARK_BENCHMARK_SUMMARY.md): two-direction manual landmark benchmark for brown cricket and black cricket descriptors.
- [Cricket Shared-PCA K-Means Clustering Summary](CRICKET_PCA_CLUSTERING_SUMMARY.md): shared K-means cluster maps (K=6, K=10) for brown cricket and black cricket descriptors, with a quantitative check that one cluster consistently isolates legs/antennae.
- [How to Interpret the Cricket K-Means Results](CRICKET_KMEANS_BODY_PART_INTERPRETATION.md): landmark-based explanation of what the clusters say about body-part semantics and bilateral symmetry, including why K=100/K=500 are not interpretable anatomical maps.
